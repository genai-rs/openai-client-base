# openai-client-base 0.17.0 → 0.18.0: `Box` only where a type contains itself

This release generates with `timvw-rust` 0.10.0 and its `boxOnlyCycles` option (Milestone 3.1 of the
[generator design](https://claude.ai/artifact/ABar8Up91gjVMDHgHL1GE3)). The OpenAI spec is unchanged.

Until now, every field or enum variant that holds another model held it as `Box<T>`. Now a model is boxed only
where the type graph needs it: a type that contains itself, directly or through other types, has no finite size
without a pointer. The current spec has no cycle beyond a handful of self-references, so nearly every `Box` is gone.
The machine-readable census is `api-diff-0.17.0-to-0.18.0.json` in this folder.

## What stays the same

- Every type, field, variant and function keeps its name. No type is added or removed.
- The JSON on the wire is the same: serde treats `Box<T>` and `T` alike.
- Constructors (`new`) and builders take the same arguments. They already took `T`, not `Box<T>`.
- Derives and serde attributes are unchanged.

## What changes

- 1310 struct fields: `Box<models::T>` becomes `models::T`, also inside `Option<..>`.
- 972 enum variants: `Variant(Box<models::T>)` becomes `Variant(models::T)`.
- Still boxed, because the type contains itself: `GrammarFormat.grammar` and the single-variant unions
  `AuditLogActor`, `BetaMcpToolCallError`, `McpToolCallError` and `TracingConfiguration`.

## Migrating

- Building a value: drop the `Box::new(..)` around the field or variant payload.
  `Tool::Function(Box::new(f))` becomes `Tool::Function(f)`, and `req.item = Some(Box::new(x))` becomes
  `req.item = Some(x)`.
- Reading a value: drop the dereference. `match &*item.content` becomes `match &item.content`.
  `as_deref()` on an `Option<Box<T>>` becomes `as_ref()`.
- Code that only reads through field access (`item.content.text`) or uses the builders compiles unchanged,
  because `Box<T>` dereferences to `T`.
