[![license](https://img.shields.io/crates/l/openai-client-base)](#license)

A low-level async Rust client for the [OpenAI](https://openai.com) API: one function per operation and a type per
schema of OpenAI's [published OpenAPI specification](https://github.com/openai/openai-openapi). The code is generated by
[timvw-rust](https://github.com/timvw/openapi-generator-timvw-rust) from the upstream spec as published; nothing is
patched afterwards. Requests go through [`timvw-rust-runtime`](https://docs.rs/timvw-rust-runtime), a
[tower](https://docs.rs/tower) service (reqwest unless you replace it) with retries.

It is a foundation for higher-level clients such as
[openai-ergonomic](https://github.com/genai-rs/openai-ergonomic); use it directly when you want every endpoint, raw.

## Quick start

```bash
cargo add openai-client-base
```

```rust,no_run
use openai_client_base::apis::{configuration::Configuration, responses_api};
use openai_client_base::models::CreateResponse;

# async fn run() -> Result<(), Box<dyn std::error::Error>> {
let mut configuration = Configuration::new();
configuration.bearer_access_token = Some(std::env::var("OPENAI_API_KEY")?.into());

let mut request = CreateResponse::new();
request.model = Some("gpt-5".to_owned());
request.input = Some("Say hello in three languages.".to_owned());
let response = responses_api::create_response()
    .configuration(&configuration)
    .create_response(&request)
    .call()
    .await?;
println!("{}", response.id);
# Ok(())
# }
```

## Key features

- **Every endpoint and webhook** of the spec, checked on each generation ([generation](guides/generation.md)).
- **Typed streaming**: `text/event-stream` operations return a stream of the spec's event type
  ([usage](guides/usage.md#streaming)).
- **Uploads** from paths, bytes or streams (`timvw_rust_runtime::Upload`), streamed with a known length and re-sent on
  retry ([usage](guides/usage.md#uploading-files)).
- **A tower client**: retries of `429`, `408`, `5xx` and failed connections honouring `Retry-After`, timeouts,
  logging, your own middleware, and per-call headers, query parameters or base URL
  ([HTTP client](guides/http-client.md)).
- **Cargo features per API group** (`responses`, `audio`, …) and `-types` features with only the models; builds for
  `wasm32-unknown-unknown` ([Cargo features](guides/cargo-features.md)).
